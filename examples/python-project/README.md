# Python 인수 샘플

금액은 센트 단위 정수다. `total_cents([100, 100]) == 200`처럼 금액이 같아도 각각의 주문 항목을 모두 더한다.

```bash
python3 -m unittest discover -s tests -v
```

초기 테스트는 서로 다른 금액과 빈 주문만 확인한다. 중복 금액 누락은 의도적으로 테스트가 놓치는 조건이다. 인수 검사는 임시 저장소에서 `sum(set(items))` 버그를 넣고, 리뷰 후 `sum(items)`로 되돌리며 새로운 중복 회귀 테스트를 추가한다.

실제 검증용 PR 세 가지:

- 정상: 중복 항목을 유지하는 합산. 의도와 검사 방법을 PR에 명시한다.
- 버그: `sum(set(items))`로 바꾸어 기존 테스트는 통과하지만 금액이 작아지는 경우.
- 민감: `auth/access.py` 변경. 모델이 low라고 해도 사람 확인이 필요하다.

이 샘플에는 실제 계정·고객 데이터·배포가 없다. 6·7번 방어 계층은 적용 조건과 후속 작업을 기록하고 운영 검증으로 표시하지 않는다.
